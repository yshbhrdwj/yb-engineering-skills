# Security reporting

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/yshbhrdwj/yb-engineering-skills/security/advisories/new). Do not publish credentials, sensitive prompts, personal data, or exploit details in a public issue.

Include the affected commit, skill or helper, a minimal sanitized reproduction, expected and actual behavior, impact, and any suggested mitigation. Do not test against other people's systems or real data without permission. No response-time or remediation guarantee is implied.

The current `main` branch is maintained. Older copied installations do not update automatically; review changes and use the installer when ready. There is no long-term support commitment for historical versions.

These skills are instructions, not a security boundary. They cannot grant tools permissions, prove legal compliance, guarantee vulnerability detection, or replace appropriate review. Check scripts and changes before executing them; use authorized test environments for consequential actions.
